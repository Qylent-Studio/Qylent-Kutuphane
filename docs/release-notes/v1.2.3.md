## Windows Akıllı Uygulama Denetimi

Bu sürümün Setup EXE dosyası güvenilir bir sertifika yetkilisinden alınmış kod imzası taşımaz. Windows 11 Akıllı Uygulama Denetimi imzasız ve henüz itibar kazanmamış uygulamaları engelleyebilir. Akıllı Uygulama Denetimi'ni kapatmanız önerilmez; yalnızca resmi GitHub Release varlığını indirin ve yayımlanan SHA-256 özetiyle dosyayı doğrulayın. Dosya bütünlüğü kontrolü Windows engelini kaldırmaz. Kalıcı dağıtım yolu güvenilir kod imzası veya Microsoft Store paketidir. [Microsoft açıklaması](https://learn.microsoft.com/en-us/windows/apps/develop/smart-app-control/overview).
