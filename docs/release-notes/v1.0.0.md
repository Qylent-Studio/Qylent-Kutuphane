# Qylent Kütüphane v1.0.0

Qylent Kütüphane'nin ilk genel Windows sürümü.

## Öne çıkanlar

- Kitap başlığı, fiziksel kopya ve üye yönetimi
- Barkodla ödünç, iade ve uzatma akışları
- FIFO ayırtma sırası ve gecikme takibi
- Yönetici korumalı ayarlar ve işlem günlüğü
- Özelleştirilebilir Excel raporları
- Parola korumalı elle ve otomatik yedekleme
- Çevrimdışı, Türkçe ve self-contained Windows kurulumu

## Kurulum

Bu sürüme ekli `Qylent-Kutuphane-Setup-1.0.0.exe` dosyasını indirin ve kurulum sihirbazını tamamlayın. Ayrıca .NET kurulumu gerekmez.
