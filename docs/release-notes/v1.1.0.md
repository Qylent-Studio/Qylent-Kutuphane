# Qylent Kütüphane v1.1.0

Yerel olarak üretilen, henüz GitHub Release olarak yayımlanmamış yükseltme adayıdır.

## Değişiklikler

- Üye yönetimine arşivliler dahil arama, seçim, ayrıntı yükleme, güncelleme, arşivleme ve güvenli silme eklendi.
- Ödünç kuralları, görevliler ve özel üye alanları için tam yönetim akışları eklendi.
- Geçmişi bulunan görevli ve değeri bulunan özel alanlar kalıcı silinmez; devre dışı bırakılır.
- Setup aynı uygulama kimliği ve önceki kurulum dizini üzerinden yerinde yükseltme yapar.
